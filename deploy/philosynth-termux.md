# PhiloSynth в Termux на Android

## Сперва — что здесь работать не будет

| Слой | В Termux | Почему |
|---|---|---|
| Сервер, страница, каталог, просмотр, импорт, экспорт | **да** | Node и PostgreSQL под Android есть |
| Гостевой вход: `/`, `/explore`, `/synthesis/:id` | **да** | обычные HTTP-пути, ничего особенного |
| Генерация концепций | **только со своим ключом** | нужен `ANTHROPIC_API_KEY` или ключ, введённый в интерфейсе (BYO-Key) |
| Биллинг: пополнение, подписки | **только на стенде** | настоящий Stripe требует публичного адреса для webhook |
| Браузерная приёмка (тесты 84, 86, 87 и прочие) | **нет** | им нужен Chrome 131 через puppeteer |
| `typecheck`, `check:dotfiles`, `check-map-04`, `css-parity` | да | это Node и Python по файлам |

Последняя пара строк важнее, чем кажется. Проверки по файлам на телефоне идут, браузерные — нет. А правило проекта — «беседа заканчивается приёмкой» — без браузерных наборов неисполнимо. Значит **Termux годится для эксплуатации и не годится для разработки.** Правку исходника оставьте машине с Chrome (`deploy/philosynth-ubuntu.md`).

## Где может не выйти вовсе

**`node-canvas`.** Сервер зависит от него с беседы 4.2 (экспорт в PNG), пребилдов под Android нет, аддон собирается из исходников — до десяти минут и почти всё время установки. Без собранного canvas сервер **не стартует вовсе**: `index.ts` статически тянет `routes/export.ts` → `png-exporter.ts` → `import "canvas"`. Скрипт проверяет, что модуль грузится, отдельным шагом — иначе вы узнали бы о поломке из невнятного `ERR_DLOPEN_FAILED` в логе.

**Память.** PostgreSQL, Redis, `tsx` и vite вместе укладываются примерно в 700–900 МБ. На телефоне с 3 ГБ это проходит, с 2 ГБ Android начнёт убивать процессы.

## Что нужно

- **Termux из F-Droid**, а не из Play Store: версия в Play заброшена и `pkg` в ней ломается.
- Android 7 и новее, arm64.
- 2,5–3 ГБ свободного места: `node_modules` вместе со сборкой canvas — около двух.
- 3 ГБ ОЗУ и больше.

## Установка

```bash
termux-setup-storage          # один раз, разрешить доступ к памяти
pkg install -y git curl
git clone https://github.com/Ranatar/philosynth.git ~/philosynth
bash ~/philosynth/deploy/philosynth-termux.sh
```

Одна команда делает всё: пакеты, PostgreSQL, Redis, клон, `.env` с
сгенерированным `API_KEY_ENCRYPTION_SECRET`, зависимости, сборку canvas,
девять миграций и четыре сида. Занимает от двадцати минут до часа, почти
всё время — canvas.

**Затем обязательно:**

```bash
bash ~/philosynth/deploy/philosynth-termux.sh admin
```

Роль администратора в сервисе иначе не получить — ни регистрацией, ни
правкой в интерфейсе (беседа 8.1). Без неё недостижимы страница промптов
и правка каталогов типов. Пароль спрашивается с клавиатуры, чтобы не
осесть в истории оболочки. Следующих администраторов назначайте уже
вкладкой «Доступ» в `/admin/prompts`: вторым прогоном скрипта второго не
завести — там стоит заслон.

## Управление

```bash
bash philosynth-termux.sh start     # база, кэш, сервер, клиент
bash philosynth-termux.sh stop      # остановить всё
bash philosynth-termux.sh status    # что живо + чего не хватает
bash philosynth-termux.sh doctor    # только диагностика
bash philosynth-termux.sh canvas    # пересобрать аддон
bash philosynth-termux.sh admin     # первый администратор
bash philosynth-termux.sh stand     # стенд биллинга без Stripe
```

`status` отвечает не только «что запущено», но и на два вопроса, ответ на
которые выглядит как поломка, а означает недоделанную установку: сколько
администраторов и сколько активных тарифов.

### Обновление

```bash
bash philosynth-termux.sh stop
git -C ~/philosynth pull
(cd ~/philosynth && npm install --no-audit --no-fund)
bash philosynth-termux.sh            # setup: миграции и сиды, остальное — skip
bash philosynth-termux.sh start
```

Сначала `stop`, в конце `start` — обязательно. Сервер идёт под `tsx watch` и
на `git pull` перезапускается сам, прогревая кэш шаблонов и конфигов ДО
посева новых версий; кэш в Redis бессрочный, посев его не сбрасывает —
сбрасывает только старт сервера. Иначе новый код работает на старых
конфигах (с беседы 10.1 — задание критики и карта подразделов расходятся).
С миграции `0008` есть и второй довод: новый код читает колонку, которой до
`setup` нет, и перезапущенный `git pull` сервер до миграции отвечает ошибками
на всё, что касается синтезов. Концепции, импортированные до `0008`, древа из
файла не получат — только повторным импортом файла.
Если сервер был запущен, `setup` предупредит и назовёт команду. `npm install`
— рукой: `setup` зависимости не переустанавливает, когда `node_modules` на
месте (canvas при этом не пересобирается — минуты, а не час).

## Деньги и генерация

Ключ Anthropic можно не класть в `.env`, а ввести свой в интерфейсе
(BYO-Key, беседа 6.1) — на телефоне это обычно и есть способ платить.
Секрет шифрования ключей генерируется скриптом; **его смена делает уже
сохранённые ключи нечитаемыми**, так что не трогайте `.env` наугад.

Пополнение баланса и подписки без `STRIPE_SECRET_KEY` отвечают 503. Чтобы
пощёлкать платный путь целиком, поднимите стенд:

```bash
bash philosynth-termux.sh stand            # мок Stripe вместо настоящего
bash philosynth-termux.sh stand --status
bash philosynth-termux.sh stand --stop
```

Деньги там ненастоящие, код настоящий.

## Гостевой вход

После бесед 8.6 и 8.7 адрес в домашней сети можно давать кому угодно.
Без входа открыты `/` (рассказ о проекте, живые карточки, цены),
`/explore` (публичный каталог) и `/synthesis/:id` (публичная концепция).

Гостю **никогда** не показываются стоимость, токены, логи и запросы к
модели — это потолок, а не настройка автора. Чтобы адрес был виден с
других устройств, клиент нужно поднять с `--host`:
`npm run dev:client -- --host`.

## Три особенности Android

**Засыпание.** Скрипт берёт `termux-wake-lock` на время работы. Без него
Android усыпит процессы через несколько минут неактивности, и сервер
перестанет отвечать, хотя `status` будет считать его живым.

**Убийца процессов.** При нехватке памяти Android гасит сначала
PostgreSQL. Признак — сервер отвечает 500 на всё подряд; лечится
`stop` и `start`.

**Хранилище.** `~/storage/downloads` появляется только после
`termux-setup-storage`, и через него удобно забирать экспортированные
файлы концепций.

## Резервное копирование

Всё ценное — в базе:

```bash
pg_dump philosynth > ~/storage/downloads/philosynth-$(date +%F).sql
```

Отдельно сохраните `API_KEY_ENCRYPTION_SECRET` из `.env` **вне телефона**:
потеряете его вместе с телефоном — потеряете все сохранённые ключи
Anthropic, и вводить их придётся заново.

## Разумная граница

размещение оставьте другим машинам: первое — `philosynth-ubuntu.md`,
второе — `philosynth-hosting.md`.
